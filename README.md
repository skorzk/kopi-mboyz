# Kasir Kopi (PWA)

File: index.html, manifest.json, sw.js, icon-192.png, icon-512.png, icon-maskable-512.png

## Hosting di GitHub Pages
1. Buat repository baru di github.com (misal: kasir-kopi), set Public.
2. Klik "Add file" > "Upload files", upload SEMUA file (tanpa folder tambahan), lalu Commit.
3. Settings > Pages > Source: "Deploy from a branch" > Branch: main, folder: / (root) > Save.
4. Tunggu 1-2 menit, buka https://USERNAME.github.io/kasir-kopi/ di Chrome HP.
5. Menu ⋮ > "Instal aplikasi" (atau "Tambahkan ke layar utama").

## Update versi
Kalau mengubah index.html, ganti angka di sw.js (kasir-kopi-v1 jadi v2) supaya HP memuat versi baru.

## Data
Disimpan di browser HP (IndexedDB). Pakai tab Riwayat > Cadangan data untuk simpan/pulihkan.
